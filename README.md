# 🐾 냥냥 낚싯대

고양이 낚싯대로 고양이와 놀아주는 웹 미니게임. **제한 시간 안에 고양이의 도파민을 100%로** 채우면 클리어. 총 5스테이지.

## 실행

ES 모듈을 쓰므로 `file://`로는 열리지 않습니다. 정적 서버로 여세요 (의존성 없음).

```bash
npm start            # = node tools/serve.mjs → http://localhost:8080
npm run balance      # 헤드리스 밸런스 시뮬레이션 (봇 5종 × 5스테이지)
```

## 규칙 (핵심 루프)

| 단계 | 내용 |
|---|---|
| 흔들기 | 낚싯대를 흔들면 **흥미**↑. 흥미가 표시선을 넘으면 고양이가 노림 |
| 웅크림 → 멈칫(!!) | 엉덩이를 씰룩이다 멈추면 곧 덮침 — 이 예고를 읽는 게 핵심 스킬 |
| 아깝게 피함 | **흥분도**↑ (+약간의 도파민). 단 연속으로 놓치면 흔들어도 반응이 둔해짐 |
| 크게 빗나감 | 흥미가 크게 떨어짐 → 0이 되면 **삐짐**(몇 초간 반응 없음) |
| 잡혀줌 | 도파민 = 기본값 × (흥분도 배율). 흥분도 0에서 잡히면 "시시해…" (×0.2) |
| 연속 시시함 | 쉽게 잡혀주기를 반복하면 도파민 추가 감소 + 흥미 하락 |

**정답 리듬:** 아깝게 2~3번 피하기 → 흥분도가 높을 때 잡혀주기.

## 스테이지

| # | 고양이 | 특징 |
|---|---|---|
| 1 | 보리 (치즈 아기냥) | 느리고 서툼. 튜토리얼 힌트 |
| 2 | 모찌 (게으른 뚱냥이) | 흥미가 빨리 식음 → 계속 흔들어야 함 |
| 3 | 고등어 (사냥꾼) | 빠름 + 움직임 예측(lead) |
| 4 | 까미 (턱시도 까칠냥) | 공중 추적, 시시한 포획 패널티 큼, 삐지면 도파민 감소 |
| 5 | 대장 (노르웨이숲 보스) | 가장 빠름 + 강한 공중 추적 + 연속 덮치기 |

## 조작 (기기 자동 감지, 안내 문구도 기기별로 바뀜)

| | 터치 | 마우스 | 키보드 | 게임패드 |
|---|---|---|---|---|
| 낚싯대 이동 | 드래그(상대) / 손가락 위치(절대, 설정) | 이동 | WASD / 방향키 | L 스틱 (R 스틱 보조) |

## 구조 — PC·콘솔 포팅을 고려한 분리

```
src/
  core/        ← 순수 게임 로직 (DOM·입력·렌더 의존 0). Node에서 그대로 실행됨
    Session.js   스테이지 1판: 입력은 { target:{x,y}, twitch } 추상 명령만 받음
    Cat.js       고양이 상태머신 + 흥미/흥분도/도파민
    Lure.js      낚싯대 끝 장난감 (스프링 추종) + 흔들기 측정
    stages.js    스테이지 데이터 (밸런스 수치 전부 여기)
  input/       ← 기기 → Action 정규화
    bindings.js  Action 정의 + 키보드/게임패드 바인딩 테이블 + 기기별 안내 문구
    InputManager.js  터치/마우스/키보드/Gamepad API → InputFrame
  render/      ← Canvas 2D 그리기 전용 (로직이 계산한 상태를 그리기만)
  ui/          ← DOM 메뉴/HUD. 포인터 클릭과 Action 내비게이션이 같은 버튼을 조작
  audio/       ← WebAudio 합성 효과음 (에셋 없음)
  platform/    ← 저장소/진동 추상화 (콘솔·앱 SDK로 교체 지점)
tools/
  balance.mjs  봇 시뮬레이션으로 밸런스 검증
  serve.mjs    무의존 정적 서버
```

포팅 시 교체 지점:
- **입력**: `bindings.js` 테이블 + `InputManager`의 기기 어댑터. 게임은 `InputFrame`만 봄
- **저장/진동/업적**: `platform/platform.js`
- **렌더링**: `render/`만 교체 (예: 엔진 스프라이트). `core/`는 렌더러를 모름
- **시뮬레이션**: 120Hz 고정 스텝 + 시드 난수 → 결정적. 리플레이/네트워크/테스트에 유리
- 월드 좌표계 고정(1000×1000). 세로 화면에선 가로 640만 보여주고 카메라가 따라감
